# Satz vom Nullprodukt

Wie löst man $(x - 5)(x + 3) = 0$? Ausmultiplizieren hilft hier nicht weiter. Viel schneller geht es, wenn man sich die **Faktoren** anschaut. In diesem Abschnitt lernst du, wann ein Produkt null ist, und wie du mit Ausklammern und binomischen Formeln Gleichungen löst, die du vorher nicht lösen konntest.

**Das Wichtigste auf einen Blick**

Ein Produkt ist null, wenn **mindestens einer** der Faktoren null ist – sonst nicht.

$$
\begin{aligned}
(x - 4)(x + 1) &= 0 \\
x - 4 = 0 \quad &\text{oder} \quad x + 1 = 0 \\
x = 4 \quad &\text{oder} \quad x = -1
\end{aligned}
$$

$$L = \{-1;\, 4\}$$

Steht auf einer Seite kein Produkt, musst du zuerst **faktorisieren**: ausklammern oder eine binomische Formel rückwärts anwenden. Teile nie durch $x$, sonst geht die Lösung $x = 0$ verloren.

:::
