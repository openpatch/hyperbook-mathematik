# Ausklammern

Beim Auflösen einer Klammer wird aus einem **Produkt** eine **Summe**: $4(2a + 3b) = 8a + 12b$. Beim Ausklammern gehst du den umgekehrten Weg. Du suchst den gemeinsamen Faktor aller Glieder und machst aus der Summe wieder ein Produkt. Das brauchst du später beim Lösen von Gleichungen.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

| Schritt | Beispiel: $6ab + 3a$ |
| --- | --- |
| **Zerlegen:** Jedes Glied als Produkt schreiben. | $6ab = 3a \cdot 2b$, $\quad 3a = 3a \cdot 1$ |
| **Markieren:** Was steckt in **allen** Gliedern? | $3a$ |
| **Ausklammern:** Gemeinsamer Faktor vor die Klammer, der Rest hinein. | $3a(2b + 1)$ |
| **Probe:** Klammer wieder auflösen. | $3a \cdot 2b + 3a \cdot 1 = 6ab + 3a$ |

Wird ein ganzes Glied ausgeklammert, bleibt in der Klammer eine $1$ stehen.

:::
