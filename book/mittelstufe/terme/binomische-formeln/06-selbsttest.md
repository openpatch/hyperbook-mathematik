# Selbsttest: Binomische Formeln

Bist du fit? Hier bearbeitest du zehn gemischte Aufgaben in **15 Minuten** – ohne Taschenrechner und ohne Hinweise. Erst am Ende siehst du, was richtig war.

:::alert{info}

**Vorher noch einmal anschauen**

| Formel | Beispiel |
| --- | --- |
| $(a + b)^2 = a^2 + 2ab + b^2$ | $(x + 4)^2 = x^2 + 8x + 16$ |
| $(a - b)^2 = a^2 - 2ab + b^2$ | $(x - 4)^2 = x^2 - 8x + 16$ |
| $(a + b)(a - b) = a^2 - b^2$ | $(x + 4)(x - 4) = x^2 - 16$ |
| Zahl vor $x$ mit quadrieren | $(3x)^2 = 9x^2$ |
| Faktorisieren | Quadrate suchen, Mittelglied $2ab$ prüfen |
| Kopfrechnen | $59^2 = (60 - 1)^2$, $\;52 \cdot 48 = (50 + 2)(50 - 2)$ |

:::
