# Binomische Formeln

Wie rechnet man $(x + 3)^2$ aus? Viele schreiben einfach $x^2 + 9$ – und das ist **falsch**. Hier findest du heraus, was wirklich herauskommt. Dafür gibt es drei Formeln, die du immer wieder brauchst: beim Vereinfachen von Termen, beim Lösen von Gleichungen und sogar beim Kopfrechnen.

Gehe die Stationen der Reihe nach durch. Erst entdeckst du etwas, dann merkst du dir die Regel, dann übst du und testest dich am Ende selbst.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

| Formel | Beispiel |
| --- | --- |
| 1. binomische Formel: $(a + b)^2 = a^2 + 2ab + b^2$ | $(x + 3)^2 = x^2 + 6x + 9$ |
| 2. binomische Formel: $(a - b)^2 = a^2 - 2ab + b^2$ | $(x - 3)^2 = x^2 - 6x + 9$ |
| 3. binomische Formel: $(a + b)(a - b) = a^2 - b^2$ | $(x + 3)(x - 3) = x^2 - 9$ |

:::
