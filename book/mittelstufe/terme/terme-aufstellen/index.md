# Terme aufstellen

Wie groß wird ein Beet, wenn nur $7$ m Zaun übrig sind? Wie viel Draht braucht man für das Kantenmodell eines Quaders? Solche Fragen beantwortest du mit einem **Term**. Ein Term ist ein Rechenausdruck mit Zahlen, Variablen und Rechenzeichen, zum Beispiel $x \cdot (7 - x)$ oder $4a + 4b + 4c$.

In diesem Abschnitt lernst du, wie du aus einer Sachsituation oder aus einem Text einen Term machst und wie du einen Term umgekehrt wieder deutest.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

| | |
| --- | --- |
| Variable | ein Buchstabe, der für eine Zahl steht, z. B. $x$ für die Breite eines Beetes |
| Term | ein Rechenausdruck aus Zahlen, Variablen und Rechenzeichen, z. B. $x \cdot (7 - x)$ |
| Termwert | das Ergebnis, wenn man für die Variable eine Zahl einsetzt |
| Termtyp | wird von der **zuletzt** ausgeführten Rechnung bestimmt: Summe, Differenz, Produkt, Quotient oder Potenz |

:::
