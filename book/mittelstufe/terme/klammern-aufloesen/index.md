# Klammern auflösen

Vier Menüs mit je einem Snack für $x$ € und einem Getränk für $2$ € kosten $4 \cdot (x + 2)$ €. Ist das dasselbe wie $4x + 2$? In diesem Abschnitt lernst du das **Distributivgesetz** kennen. Damit löst du Klammern auf, auch wenn ein Minuszeichen davor steht.

**Das Wichtigste auf einen Blick**

| Regel | Beispiel |
| --- | --- |
| Der Faktor vor der Klammer wird mit **jedem** Glied in der Klammer multipliziert. | $7(4x + 3y) = 28x + 21y$ |
| Ist der Faktor negativ, gelten die Vorzeichenregeln. | $-2(3x - 5y) = -6x + 10y$ |
| Ein Minus vor der Klammer dreht **jedes** Vorzeichen in der Klammer um. | $-(3x - 2y) = -3x + 2y$ |
| Eine Summe wird durch eine Zahl dividiert, indem man **jedes** Glied dividiert. | $(6a + 9b) : 3 = 2a + 3b$ |
| Probe: Setze eine Zahl ein und vergleiche. | |

:::
