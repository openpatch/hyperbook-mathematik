# Zwei Klammern multiplizieren

Ein Grundstück wird an zwei Seiten vergrößert. Wie groß ist es danach? Wer nur die beiden neuen Streifen dazuzählt, vergisst die Ecke. In diesem Abschnitt lernst du, wie man zwei Klammern miteinander multipliziert: **jedes Glied mit jedem**.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

Man multipliziert zwei Summen oder Differenzen, indem man **jedes Glied der ersten Klammer mit jedem Glied der zweiten Klammer** multipliziert. Die Vorzeichen setzt man nach den Vorzeichenregeln.

$$(a + b)(c + d) = ac + ad + bc + bd$$

$$(x - 2)(x + 9) = x^2 + 9x - 2x - 18 = x^2 + 7x - 18$$

**Kontrolle:** Zwei Glieder mal zwei Glieder ergibt $2 \cdot 2 = 4$ Produkte, bevor man zusammenfasst.

:::
