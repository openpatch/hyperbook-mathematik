# Verhältnisgleichungen

Fotos, Bildschirme und Logos haben feste Seitenverhältnisse wie $4 : 3$ oder $16 : 9$. Wenn eine Seite bekannt ist, kannst du die andere mit einer **Verhältnisgleichung** berechnen. In diesem Abschnitt lernst du, solche Gleichungen aufzustellen und zu lösen, auch wenn die Variable im Nenner steht.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

Eine **Verhältnisgleichung** hat auf beiden Seiten ein Verhältnis, zum Beispiel $x : 4 = 3 : 8$.

1. Schreibe die Verhältnisse als Brüche: $\; \frac{x}{4} = \frac{3}{8}$
2. Multipliziere beide Seiten mit dem **Hauptnenner**. Steht $x$ im Nenner, gehört $x$ dazu.
3. Löse die Gleichung und mache die Probe.

| $x$ im Zähler | $x$ im Nenner |
| --- | --- |
| $\frac{x}{4} = \frac{3}{8} \quad \vert \cdot 4$ | $\frac{5}{4} = \frac{3}{x} \quad \vert \cdot 4x$ |
| $x = \frac{12}{8} = 1{,}5$ | $5x = 12 \quad \vert : 5$ |
| | $x = 2{,}4$ |

:::
