## Gitarrensaiten

Auf einer Gitarre klingt ein Ton höher, wenn man die schwingende Saite verkürzt. Die leere Saite ist $60$ cm lang. Für eine **Oktave** muss die schwingende Länge im Verhältnis $1 : 2$ zur ganzen Saite stehen, für eine **Quinte** im Verhältnis $2 : 3$.

:::multievent

Oktave: $x : 60 = 1 : 2$, also $x =$ {z{30}} cm.

Quinte: $x : 60 = 2 : 3$, also $x =$ {z{40}} cm.

Quarte: $x : 60 = 3 : 4$, also $x =$ {z{45}} cm.

Große Terz: $x : 60 = 4 : 5$, also $x =$ {z{48}} cm.

:::

## Saft abfüllen

:::snippet{#aufgabe}

Aus $50$ kg Äpfeln presst eine Mosterei $14$ Liter Saft.

:::

:::multievent

Aus $113$ kg Äpfeln erhält man {z{31,64}} Liter Saft.

Damit kann man {z{31}} volle Ein-Liter-Flaschen füllen.

Für $70$ Liter Saft braucht man {z{250}} kg Äpfel.

{b{x/113 = 14/50 ⇒ x = 14/50 · 113 = 31,64. Für 70 Liter: 70/y = 14/50 ⇒ 14y = 3500 ⇒ y = 250.}}

:::

## Gleichungen bauen

:::snippet{#aufgabe}

Ergänze so, dass die Gleichung die angegebene Lösung hat.

:::

:::multievent

$x : 2 = 3 : \square$ soll die Lösung $x = 3$ haben. $\;\square =$ {z{2}}

$x : 5 = \square : 7$ soll die Lösung $x = 0$ haben. $\;\square =$ {z{0}}

$x : 4 = -1 : \square$ soll die Lösung $x = -2$ haben. $\;\square =$ {z{2}}

:::
