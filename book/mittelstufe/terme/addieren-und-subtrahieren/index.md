# Terme addieren und subtrahieren

Ist $x + x^2$ dasselbe wie $2x^2$? Und darf man $3a + 2b$ zu $5ab$ zusammenfassen? In diesem Abschnitt findest du heraus, welche Glieder eines Terms sich zusammenfassen lassen und welche nicht. Außerdem lernst du, wie du prüfst, ob zwei Terme wirklich dasselbe bedeuten.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

| Regel | Beispiel |
| --- | --- |
| Gleichartige Glieder haben **dieselben Variablen mit denselben Exponenten**. | $5xy^2$ und $-3xy^2$ |
| Gleichartige Glieder fasst man zusammen, indem man die **Zahlfaktoren** addiert oder subtrahiert. | $7a + 2a = 9a$ |
| Nicht gleichartige Glieder bleiben stehen. | $x + x^2$ bleibt $x + x^2$ |
| Das Rechenzeichen gehört zum Glied dahinter. Mit ihm darf das Glied verschoben werden. | $3 - 7w + 5w = 3 + 5w - 7w$ |
| Zwei Terme sind **wertgleich**, wenn sie bei **jeder** Einsetzung denselben Wert haben. | $2a + 2b$ und $2(a + b)$ |

:::
