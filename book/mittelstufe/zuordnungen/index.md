# Zuordnungen

Wie viel Ackerfläche braucht ein Burger? Wie lange reicht ein Acker, wenn jeden Tag mehr Portionen gegessen werden? Solche Fragen beantwortest du mit **Zuordnungen**: Einer Größe wird eine andere Größe zugeordnet – der Anzahl der Portionen die Ackerfläche, der Uhrzeit der Stromverbrauch.

Dieses Kapitel **ergänzt das Arbeitsheft „Zuordnungen“**: Hier findest du ausführliche Erklärungen, interaktive Bilder zum Ausprobieren und zusätzliche Übungen mit sofortiger Rückmeldung. Die kleinen **QR-Codes im Heft** führen dich direkt zur passenden Seite.

:::snippet{#merken}

**Das Wichtigste auf einen Blick**

| | proportional | antiproportional |
| --- | --- | --- |
| Faustregel | doppelt so viel → **doppelt** so viel | doppelt so viel → **halb** so viel |
| Tabelle | **Quotienten** $\frac{y}{x}$ sind gleich | **Produkte** $x \cdot y$ sind gleich |
| Graph | Halbgerade, beginnt im Ursprung | Hyperbel, nähert sich den Achsen |
| Zuordnungsvorschrift | $y = k \cdot x$ | $y = \frac{c}{x}$ |
| Beispiel | Portionen → Ackerfläche | Portionen pro Tag → Tage |

:::
