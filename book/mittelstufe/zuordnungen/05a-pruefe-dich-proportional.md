# Prüfe dich: Proportionale Zuordnungen

Du hast im 📓 **Arbeitsheft (S. 15–20)** das Kapitel „Proportionale Zuordnungen“ bearbeitet? Dann prüfe hier, ob du alles kannst. Es gibt zehn Aufgaben rund ums Essen. Erst am Ende siehst du, was richtig war. Ein Taschenrechner ist erlaubt.

:::alert{info}

**Vorher noch einmal anschauen**

| | proportional |
| --- | --- |
| Faustregel | doppelt so viel → doppelt so viel, halb so viel → halb so viel |
| Tabelle | alle Quotienten $\frac{y}{x}$ sind gleich – das ist der Proportionalitätsfaktor $k$ |
| Vorschrift | $y = k \cdot x$ |
| Graph | Halbgerade, die im Ursprung beginnt |
| Dreisatz | erst beide Größen durch dieselbe Zahl teilen, dann beide mit derselben Zahl multiplizieren |
