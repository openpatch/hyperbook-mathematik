# Multiplizieren und Dividieren rationaler Zahlen

Du kannst schon Brüche und Dezimalzahlen multiplizieren und dividieren. Jetzt kommen negative Zahlen dazu. Die wichtigste Frage dabei: **Welches Vorzeichen hat das Ergebnis?**

## Das Wichtigste auf einen Blick

| Regel | Beispiel |
| --- | --- |
| Gleiche Vorzeichen → Ergebnis **positiv** | $(-4) \cdot (-2{,}5) = 10$ $\quad (-12) : (-3) = 4$ |
| Verschiedene Vorzeichen → Ergebnis **negativ** | $(-4) \cdot 2{,}5 = -10$ $\quad 12 : (-3) = -4$ |
| Gerade Anzahl Minuszeichen → **positiv**, ungerade → **negativ** | $(-1) \cdot (-2) \cdot (-3) = -6$ |
| Mal $(-1)$ ergibt die **Gegenzahl** | $-(-7) = 7$ |
| Durch $0$ darf man **nie** dividieren | $(-5) : 0$ ist nicht definiert |
